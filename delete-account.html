English Thru 계정 삭제

English Thru 앱에서 Google 로그인으로 생성한 계정의 삭제를 요청할 수 있습니다. 앱에 로그인하거나 앱을 다시 설치하지 않아도 요청할 수 있습니다.

현재 계정 삭제는 운영자가 요청을 확인하여 처리합니다. 이 페이지를 열거나 이메일 작성 링크를 누르는 것만으로 계정이 즉시 삭제되지는 않습니다.

삭제 요청 방법

  1. 가능하면 English Thru에 로그인할 때 사용한 Google 계정의 이메일로 요청해 주세요.
  2. 이메일 제목을 English Thru 계정 삭제 요청으로 적고, 본문에 삭제할 계정의 로그인 이메일과 계정 삭제를 요청한다는 내용을 적어 주세요. 삭제 이유는 필수가 아닙니다.
  3. 운영자가 본인 여부를 확인한 뒤 삭제를 진행하고 결과를 이메일로 안내합니다. 등록된 이메일을 사용할 수 없다면 문의하여 확인 절차를 안내받을 수 있습니다.

요청 이메일: msdos25@gmail.com
이메일 앱이 열리지 않으면 주소를 복사해 직접 보내주세요.

비밀번호, Google 인증 코드, 신분증 사본 또는 로그인 토큰을 보내지 마세요. GitHub의 공개 이슈나 댓글에 계정 정보를 남기지 마세요.

처리 기간: 본인 확인 후 지체 없이 처리하며, 접수 회신에서 예상 처리 일정을 안내합니다. 추가 확인이나 지연이 필요한 경우 사유와 일정을 이메일로 알려드립니다.

삭제 대상

  • English Thru의 Supabase Auth 계정과 연결된 인증 사용자 정보
  • 서비스가 보유한 해당 계정의 서버 사용자 데이터(연결된 프로필 정보가 있는 경우 포함)

삭제된 계정의 서버 데이터는 복구할 수 없습니다. 이후 Google 로그인을 다시 하면 새 English Thru 계정이 만들어질 수 있습니다. Google 계정 자체나 다른 서비스의 데이터는 삭제되지 않습니다.

법령에 따라 보관해야 하는 정보가 있는 경우 해당 항목, 보관 사유와 기간을 개별 안내합니다. 삭제 요청 이메일은 본인 확인과 처리 안내를 위해 필요한 동안만 보관한 뒤 삭제합니다.

기기에 저장된 학습 데이터

현재 학습 진도, 문장 평가·복습 기록 및 학습 설정은 기기에 저장됩니다. 서버 계정 삭제나 로그아웃만으로 기기의 학습 데이터가 자동으로 지워지지는 않습니다.

직접 제거하려면 Android의 설정 → 앱 → English Thru → 저장공간 → 데이터 삭제를 이용해 주세요. 메뉴 이름은 기기에 따라 다를 수 있습니다. 이 작업은 해당 기기의 로그인 상태와 로컬 학습 데이터를 함께 지우며 되돌릴 수 없습니다.

앱 제거 시 해당 기기의 앱 데이터도 제거되지만, 기기 백업·복원 설정에 따라 재설치할 때 복원될 수 있습니다. 여러 기기에서 이용했다면 각 기기의 데이터를 별도로 확인해 주세요. 앱을 제거하는 것만으로 서버 계정이 삭제되지는 않습니다.
