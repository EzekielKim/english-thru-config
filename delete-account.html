English Thru 계정 삭제

English Thru 계정은 앱의 MY → 계정 → 계정 삭제에서 직접 삭제할 수 있습니다. 앱 내 계정 삭제 기능이 제공되는 버전에서 아래 절차를 이용해 주세요.

계정을 삭제하면 복구할 수 없습니다. Google 계정 자체는 삭제되지 않습니다. 이 안내 페이지를 열기만 해서는 삭제되지 않습니다.

앱에서 직접 삭제하기

  1. 삭제할 English Thru 계정으로 앱에 로그인합니다.
  2. MY → 계정 → 계정 삭제를 선택합니다.
  3. 삭제 경고를 확인하고 계정 삭제를 눌러 최종 확인합니다. 원하지 않으면 취소할 수 있습니다.
  4. 서버는 현재 로그인한 사용자를 확인한 뒤 해당 계정의 서버 사용자 데이터와 인증 계정을 삭제합니다. 성공 후 해당 기기의 학습 데이터와 로그인 정보를 정리하고 로그인 화면으로 이동합니다.

삭제에는 인터넷 연결이 필요합니다. 삭제 메뉴가 없거나 서버 연결·삭제 오류로 진행할 수 없다면 아래 이메일로 요청해 주세요. 실패 메시지가 표시된 경우 삭제 완료를 단정하지 말고 다시 시도하거나 문의해 주세요.

앱을 사용할 수 없을 때

앱 로그인이나 재설치 없이도 이메일로 계정 삭제를 요청할 수 있습니다.

  1. 가능하면 English Thru에 로그인할 때 사용한 Google 계정의 이메일로 요청해 주세요.
  2. 이메일 제목을 English Thru 계정 삭제 요청으로 적고, 본문에 삭제할 계정의 로그인 이메일과 계정 삭제를 요청한다는 내용을 적어 주세요. 삭제 이유는 필수가 아닙니다.
  3. 운영자가 본인 여부를 확인한 뒤 삭제를 진행하고 결과를 이메일로 안내합니다. 등록된 이메일을 사용할 수 없다면 문의하여 확인 절차를 안내받을 수 있습니다.

삭제 대상

  • English Thru의 Supabase Auth 계정과 연결된 인증 사용자 정보
  • 해당 계정의 프로필 정보와 서버에 저장된 코스 진행·푸시 기기 등록 정보가 있는 경우 해당 데이터

삭제된 계정의 서버 데이터는 복구할 수 없습니다. 이후 Google 로그인을 다시 하면 새 English Thru 계정이 만들어질 수 있습니다. Google 계정 자체나 다른 서비스의 데이터는 삭제되지 않습니다.

법령에 따라 보관해야 하는 정보가 있는 경우 해당 항목, 보관 사유와 기간을 개별 안내합니다. 삭제 요청 이메일은 본인 확인과 처리 안내를 위해 필요한 동안만 보관한 뒤 삭제합니다.

기기에 저장된 학습 데이터

앱에서 계정 삭제가 성공하면 삭제를 실행한 기기의 학습 진도, 문장 평가·복습 기록, 최근 학습, 학습 설정, 광고 일일 해금 정보와 로그인 정보를 정리합니다. 기기 저장소 오류로 정리가 실패하면 앱에서 안내하며, 다시 실행할 때 정리를 재시도합니다.

운영자가 이메일 요청으로 서버 계정을 삭제한 경우, 다른 기기에 남은 기록, 기기 백업 데이터는 서버에서 직접 지울 수 없습니다. 단순 로그아웃은 학습 기록을 지우지 않습니다.

직접 제거하려면 Android의 설정 → 앱 → English Thru → 저장공간 → 데이터 삭제를 이용해 주세요. 메뉴 이름은 기기에 따라 다를 수 있습니다. 이 작업은 해당 기기의 로그인 상태와 로컬 학습 데이터를 함께 지우며 되돌릴 수 없습니다.

앱 제거 시 해당 기기의 앱 데이터도 제거되지만, 기기 백업·복원 설정에 따라 재설치할 때 복원될 수 있습니다. 여러 기기에서 이용했다면 각 기기의 데이터를 별도로 확인해 주세요. 앱을 제거하는 것만으로 서버 계정이 삭제되지는 않습니다.
