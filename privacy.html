English Thru 개인정보처리방침

English Thru는 로그인과 영어 학습 서비스 운영에 필요한 정보를 처리합니다. 이 방침은 Android 앱의 개인정보 처리 방법을 설명합니다.

1. 처리하는 정보와 이용 목적

  • 계정 정보: Google 로그인으로 전달되는 이메일, 이름, 프로필 이미지 주소, 로그인 제공자 및 계정 식별 정보를 Supabase Auth에서 처리합니다. 사용자 구분, 로그인, 앱 내 계정 정보 표시에 사용합니다. Google 계정 비밀번호를 앱에서 수집하지 않습니다.
  • 로그인 유지 정보: Supabase 인증 세션을 기기에 저장하여 앱을 다시 열 때 로그인 상태를 복원합니다.
  • 기기 내 학습 정보: 코스 진도·완료 시각, 이어하기 정보, 문장 평가·복습 기록, 학습 표시 설정을 기기의 앱 저장소(AsyncStorage)에 저장합니다. 학습을 이어가고 복습 대상을 정하는 데 사용하며, 현재 코스 진행 데이터를 서버에 동기화하지 않습니다.
  • 문의·삭제 요청 정보: 사용자가 이메일로 보내는 회신 주소와 요청 내용을 문의 응대, 본인 확인 및 계정 삭제 처리에 사용합니다. 비밀번호나 인증 코드를 보내지 마세요.

서버에 계정과 연결된 프로필 정보가 생성되어 있는 경우에도 계정 관리 목적의 사용자 정보로 취급하며, 계정 삭제 시 함께 확인합니다.

2. 현재 사용하지 않는 기능

현재 앱은 광고 SDK, 푸시 알림, 카메라, 마이크 녹음, 음성 인식(STT), 갤러리 및 외부 저장소 접근 기능을 사용하지 않습니다. 문장 읽어주기(TTS)는 기기에 설정된 음성 합성 기능을 이용합니다. 음성 처리 방식과 네트워크 이용 여부는 사용자가 선택한 TTS 엔진 및 기기 설정에 따라 달라질 수 있습니다.

3. 보관 및 삭제

서버의 계정 정보는 서비스 계정을 유지하는 동안 보관하며, 계정 삭제 요청이 처리되면 Supabase Auth 계정과 서비스가 보유한 해당 계정의 서버 사용자 데이터를 삭제합니다. 문의 내용은 응대와 요청 처리에 필요한 동안 보관하며, 처리 목적이 끝나면 삭제합니다.

기기에 저장된 학습 정보는 로그아웃하거나 서버 계정을 삭제하는 것만으로 자동 삭제되지 않습니다. Android 설정에서 English Thru의 앱 데이터를 삭제하여 제거할 수 있습니다. 앱 제거 시에도 해당 기기의 앱 데이터가 제거되지만, 기기 백업·복원 설정에 따라 재설치할 때 복원될 수 있습니다.

법령에 따라 별도 보관이 필요한 정보가 있는 경우에는 해당 정보, 근거 및 보관 기간을 안내하고 그 목적에 한해 보관합니다.

4. 외부 서비스

  • Google: Google 계정으로 본인을 인증하는 데 사용합니다. Google의 정보 처리는 Google 개인정보처리방침을 참고해 주세요.
  • Supabase: 계정 인증, 인증 사용자 정보 보관 및 세션 관리에 사용합니다. Supabase 개인정보처리방침을 참고해 주세요.
  • GitHub Pages: 이 공개 안내 사이트의 호스팅에 사용합니다. 사이트 접속 정보의 처리는 GitHub 개인정보처리방침을 참고해 주세요. 이 사이트에 별도 광고·분석 스크립트는 설치하지 않습니다.

5. 사용자 권리와 계정 삭제

자신의 개인정보에 대한 열람, 정정, 삭제 또는 처리 정지를 문의처로 요청할 수 있습니다. 다른 사람의 정보를 보호하기 위해 요청자 본인임을 확인할 수 있으며, 처리 결과나 제한 사유를 안내합니다.

계정 삭제는 English Thru 계정 삭제 안내에서 절차를 확인해 주세요. 이 절차는 English Thru 계정에만 적용되며 Google 계정 자체를 삭제하지 않습니다.
